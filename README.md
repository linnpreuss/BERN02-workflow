# Palmer Penguins Analysis

This repository contains a reproducible Jupyter Notebook analysing the relationship between penguin flipper length and body mass.

# Requirements
The workflow requires:

- Python 3.13.5
- pandas 2.3.3
- numpy 2.4.4
- matplotlib 3.10.1
- seaborn 0.13.2

The required package versions are specified in `environment.yml`.

# How to run
1. Create the environment using `environment.yml`.
2. Activate the environment.
3. Open `BERN02_workflow.ipynb` in Jupyter Notebook.
4. Run the notebook cells from top to bottom.

# Reproducibility
Package versions are pinned in `environment.yml`.
